# Открытие трека в приложении Яндекс Музыки

## Цель

Кнопка Discord Rich Presence должна открывать текущий трек в настольном приложении Яндекс Музыки, если для него удалось надёжно определить ID альбома и трека.

## Поведение

- Существующая кнопка «Открыть трек» заменяется на «Открыть в Яндекс Музыке».
- Ссылка кнопки имеет формат `yandexmusic://album/{albumId}/track/{trackId}`.
- Используются только ID, полученные из единственного точного совпадения поиска. Неоднозначный результат, ошибка сети или неполные данные оставляют активность без кнопки.
- Других кнопок и серверной инфраструктуры не добавляется.

## Поток данных

`TrackResolver` продолжает искать трек по названию и исполнителю, проверять точное совпадение и получать ID альбома и трека. Вместо веб-адреса он возвращает диплинк Яндекс Музыки. `ActivityMapper` передаёт его в модель активности, а `DiscordIpcClient` отправляет одну кнопку с новым текстом и URL.

Windows-схема `yandexmusic:` уже зарегистрирована приложением на текущем компьютере. Ссылка рассчитана на устройство человека, который нажимает кнопку: для открытия настольного приложения у него должна быть установлена Яндекс Музыка и зарегистрирован обработчик схемы.

## Ограничения и ошибки

Публичная документация Discord описывает Rich Presence кнопки как URL, открываемые в браузере пользователя, но не уточняет обработку пользовательских URI-схем. Поэтому фактический переход по `yandexmusic:` в Discord нужно проверить вручную на карточке активности с другого аккаунта. Если Discord не передаст такую ссылку обработчику Windows, потребуется отдельное решение с HTTPS-переходом; оно не входит в эту реализацию.

Если поиск Яндекс Музыки не находит ровно один проверенный трек, приложение продолжает показывать название, исполнителя и обложку (если она найдена), но не отправляет кнопку.

## Проверка

- Собрать приложение в Release-конфигурации.
- На компьютере с установленной Яндекс Музыкой проверить открытие конкретного трека по диплинку.
- Посмотреть активность с другого аккаунта Discord и проверить кнопку, название и переход к текущему треку.
- Убедиться, что при неоднозначном результате или недоступности поиска кнопка отсутствует, а текстовая активность продолжает работать.
