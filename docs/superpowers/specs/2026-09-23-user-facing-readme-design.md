# Короткий README для пользователей

## Цель

Сделать главную страницу репозитория понятной человеку, который хочет скачать утилиту и увидеть текущий трек Яндекс Музыки в Discord. Убрать из первого экрана команды разработки и внутренние детали Discord.

## Структура

- Одно простое предложение о том, что делает программа.
- Ссылка на последний релиз и три шага установки для Windows.
- Кратко: программа работает в трее, подключается сама, автозапуск можно включить в меню.
- Небольшой раздел «Если не работает» с проверкой настольных приложений и разрешения показывать активность в Discord.
- Короткое честное пояснение о приватности, поиске обложек и отсутствии функции «Слушать вместе».
- Ссылка на отдельный `docs/development.md` для сборки, тестов и технического устройства.

## Отдельная документация

В `docs/development.md` перенести текущие команды запуска, публикации и тестирования, параметры собственного Application ID и объяснение источника медиаданных и поиска обложки. Не менять поведение приложения или ссылки на релиз.

## GitHub

Краткое описание репозитория: «Показывает музыку из приложения Яндекс Музыки в Discord». Название репозитория и релизные файлы не менять, чтобы существующие ссылки продолжили работать.

## Проверка

Проверить ссылки и команды после переноса, отсутствие потерянных важных предупреждений и то, что скачивание понятно без знания GitHub Actions, API и Discord Developer Portal.
