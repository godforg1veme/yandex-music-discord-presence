# Полное переименование проекта

## Цель

Убрать `Presence` из текущих пользовательских и технических имён. В Discord активность должна читаться «Слушает Yandex Music».

## Имена

- Discord Application ID `1552113063606489088` сохраняется; публичное имя приложения уже `Yandex Music`.
- Название проекта и релиза: `Yandex Music for Discord`.
- GitHub-репозиторий: `godforg1veme/yandex-music-for-discord`.
- Исполняемый файл: `YandexMusicDiscord.exe`; архив: `YandexMusicDiscord-win-x64.zip`.
- Пространство имён, проекты .NET и тесты: `YandexMusicDiscord`.
- Названия внутренних классов должны описывать задачу и не содержать `Presence` (например, `ActivityCoordinator`, `ActivityMapper`). Стандартные термины Discord Rich Presence допустимы в техническом объяснении API, но не в названии продукта.

## Миграция

Опция автозапуска должна распознавать старую запись `YandexMusicPresence`. Если она указывает на прежнюю копию этой программы, новая версия заменяет её записью `YandexMusicDiscord`; другие записи реестра не трогать. Старую запущенную программу нужно закрыть перед первым запуском новой, чтобы две версии не спорили за статус.

## Сборка и публикация

Обновить README, документацию для разработчиков, workflow сборки и релиза, метаданные .NET, имена локальных ассетов и тесты. Исторические проектные документы можно оставить как архив предыдущего решения, но актуальные ссылки и команды должны указывать на новые имена.

Выпустить новую версию с новым именем архива. Старый релиз оставить доступным, а ссылку в README направить на последний. Проверить сборку, тесты, архив и наличие ассетов на GitHub.

## Discord

Публичный API уже возвращает имя приложения `Yandex Music`. Для запасной картинки загрузить в существующее Discord-приложение тот же значок с ключом `yandex-music`, затем обновить ключ в коде. Если портал недоступен, сохранить рабочий старый ключ до загрузки нового и не утверждать, что внутреннее переименование завершено.

После выпуска попросить пользователя закрыть старый процесс и перезапустить настольный Discord для сброса локального кэша; проверить отображаемое имя на реальной активности. Не создавать новое Discord-приложение и не запрашивать токены.
