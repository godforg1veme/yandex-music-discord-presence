## Yandex Music for Discord 0.3.0

Это обновление исправляет публикацию активности в Discord и делает карточку трека точнее.

- **Обложка и исполнители.** Поиск работает с треками, у которых указано несколько исполнителей. Неудачный поиск повторяется через 30 секунд, поэтому временный сбой не оставляет статический значок до конца трека.
- **Время воспроизведения.** Discord получает время начала трека из позиции медиасессии Windows. Счётчик больше не начинается заново в момент подключения программы.
- **Надёжная публикация.** Если ссылка на трек не найдена, активность отправляется без кнопки. Если Discord отклонит ссылку для открытия приложения, программа попробует обычную веб-ссылку.
- **Кнопка «В Яндекс Музыке».** Для точно найденного трека она ведёт через HTTPS-ссылку Яндекс Музыки к установленному приложению, если обработчик ссылки доступен на компьютере.
- **Проверка.** Добавлен сквозной тест с имитацией медиасессии, поиска Яндекс Музыки и Discord IPC. Он проверяет публикацию, обложку, время, кнопку и очистку при паузе.

Для обновления закройте прежнюю версию через значок в трее, замените `YandexMusicDiscord.exe` файлом из архива и запустите его. Настройки автозапуска сохраняются, если новый файл остаётся по прежнему пути.

Требуются Windows 10/11 x64, настольная Яндекс Музыка и настольный Discord. Поиск обложек зависит от публичного интерфейса Яндекс Музыки, а точность счётчика — от позиции, которую плеер передаёт Windows.
