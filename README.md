# Яндекс Музыка в Discord

Показывает в Discord, что вы слушаете в приложении Яндекс Музыки для Windows. В карточке будут название песни, исполнитель и, если удалось найти, обложка и ссылка на трек.

[Скачать для Windows](https://github.com/godforg1veme/yandex-music-for-discord/releases/latest)

## Как запустить

1. Скачайте архив `YandexMusicDiscord-win-x64.zip` со страницы релиза и распакуйте его в удобную папку.
2. Запустите `YandexMusicDiscord.exe`.
3. Включите музыку в [настольном приложении Яндекс Музыки](https://music.yandex.ru/download/). Discord тоже должен быть открыт. Через несколько секунд в профиле появится активность «Слушает Yandex Music».

Программа работает в системном трее. Нажмите правой кнопкой на её значок, чтобы посмотреть состояние, включить запуск вместе с Windows или выйти. Если открыть Discord или Яндекс Музыку позже, программа подключится сама. Настраивать приложение Discord или вводить токены не нужно.

Если у вас установлена старая версия, сначала выйдите из неё через меню в трее. После запуска новой версии настройка автозапуска перенесётся сама. Старый `.exe` можно удалить.

Работает на Windows 10/11 x64 с настольной версией Discord. Браузерная вкладка Яндекс Музыки не поддерживается.

## Если трек не появился

- Убедитесь, что музыка действительно играет в настольном приложении Яндекс Музыки, а не в браузере.
- Проверьте, включён ли показ активности в настройках Discord.
- Посмотрите первую строку меню программы в трее: там написано, ждёт ли она Яндекс Музыку или Discord.

При паузе или закрытии плеера активность исчезает. Если обложку найти не удалось, название и исполнитель всё равно отображаются. Функция Spotify «Слушать вместе» для такого подключения недоступна.

## Приватность

Программа не просит пароль и не хранит историю прослушивания. Текущий трек передаётся Discord, а название песни и исполнитель используются для поиска обложки в Яндекс Музыке. Собственного сервера, телеметрии и автообновления нет.

Проект не связан с Яндексом или Discord. Исходный код открыт по лицензии MIT.

Для сборки из исходников и подробностей о работе программы есть [документация для разработчиков](docs/development.md).
