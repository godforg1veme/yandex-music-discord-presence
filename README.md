# Яндекс Музыка в Discord

Показывает в Discord трек из настольной Яндекс Музыки для Windows: название, исполнителей, время воспроизведения и обложку, если её удалось найти. Если трек удалось точно определить, появляется кнопка «В Яндекс Музыке».

[Скачать для Windows](https://github.com/godforg1veme/yandex-music-for-discord/releases/latest)

## Что нового в v0.3.0

- Время в Discord синхронизируется с позицией трека, которую передаёт Windows.
- Обложки находятся и для треков с несколькими исполнителями. Если поиск временно не сработал, программа пробует снова через 30 секунд.
- Активность публикуется даже без ссылки на трек; ошибка Discord теперь видна в меню значка программы.
- Кнопка ведёт к найденному треку через ссылку Яндекс Музыки. При отсутствии обработчика настольного приложения может открыться сайт.

[Подробности обновления](https://github.com/godforg1veme/yandex-music-for-discord/releases/tag/v0.3.0).

## Как запустить

1. Скачайте архив `YandexMusicDiscord-win-x64.zip` со страницы релиза и распакуйте его в удобную папку.
2. Запустите `YandexMusicDiscord.exe`.
3. Включите музыку в [настольном приложении Яндекс Музыки](https://music.yandex.ru/download/). Discord тоже должен быть открыт. Через несколько секунд в профиле появится активность «Слушает Yandex Music».

Программа работает в системном трее. Нажмите правой кнопкой на её значок, чтобы посмотреть состояние, включить запуск вместе с Windows или выйти. Если открыть Discord или Яндекс Музыку позже, программа подключится сама. Настраивать приложение Discord или вводить токены не нужно.

Чтобы обновить программу, выйдите из старой версии через значок в трее, замените `YandexMusicDiscord.exe` файлом из нового архива и запустите его. Если программа запускается вместе с Windows, оставьте новый exe в той же папке. Настройка автозапуска старой версии переносится автоматически.

Работает на Windows 10/11 x64 с настольной версией Discord. Браузерная вкладка Яндекс Музыки не поддерживается.

## Если трек не появился

- Убедитесь, что музыка действительно играет в настольном приложении Яндекс Музыки, а не в браузере.
- Проверьте, включён ли показ активности в настройках Discord.
- Посмотрите первую строку меню программы в трее: там указано текущее состояние или причина отказа Discord. Последняя ошибка подключения также сохраняется локально в `%TEMP%\YandexMusicDiscord-discord-error.log`.

Программа проверяет трек каждые 2 секунды, отправляет изменения при смене трека и повторяет активность раз в 30 секунд. Сам счётчик в Discord идёт по времени начала трека. При паузе или закрытии плеера активность исчезает. Если обложку найти не удалось, название и исполнитель всё равно отображаются. Функция Spotify «Слушать вместе» для такого подключения недоступна.

## Приватность

Программа не просит пароль и не хранит историю прослушивания. Текущий трек передаётся Discord, а название песни и исполнитель используются для поиска обложки в Яндекс Музыке. Собственного сервера, телеметрии и автообновления нет.

Проект не связан с Яндексом или Discord. Исходный код открыт по лицензии MIT.

Для сборки из исходников и подробностей о работе программы есть [документация для разработчиков](https://github.com/godforg1veme/yandex-music-for-discord/blob/main/docs/development.md).
